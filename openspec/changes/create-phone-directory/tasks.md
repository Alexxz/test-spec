## 3. SQLite и сохранность

- [ ] 3.1 Создать файловую схему с постоянными ID, неуникальными индексами и точным сравнением; тестами проверить повторные пары, несколько совпадений, регистр, внутренние пробелы, Unicode и закрытие соединений.
- [ ] 3.2 Добавить явный режим транзакций и настройки соединения по design.md, транзакционное создание, подтверждение после commit и обработку ошибок; выполнить проверки перезапуска, SIGKILL, остановки до и после commit, SQLITE_FULL. Проверить сохранность старых записей, закрытие соединений и продолжение работы после устранения ошибки. Эксперименты check_facts.py не заменяют эти проверки приложения.
- [ ] 3.3 Реализовать проверку совместимости существующей БД и описать в README путь данных и границы гарантий; проверить повторный запуск с тем же файлом, восстановление журнала после сбоя и отказ до открытия HTTP-порта для чужих маркеров, несовместимой схемы, пустого файла, повреждения при читаемой схеме и полностью нечитаемого файла без пересоздания или изменения схемы. Проверить integrity_check при запуске и отсутствие полной проверки на каждом поиске.
