# Spec Delta

## Purpose

Сохранение подтверждённых записей между запусками и после аварийного завершения процесса на исправном носителе. Границы гарантии являются предлагаемым уточнением исходных требований.

## ADDED Requirements

### Requirement: Сохранение при штатном перезапуске

Система MUST сохранять подтверждённые записи и их идентификаторы после штатной остановки и повторного запуска с тем же хранилищем.

#### Scenario: Перезапуск
- **WHEN** создание нескольких записей подтверждено, система штатно остановлена и запущена с тем же хранилищем
- **THEN** поиск возвращает все эти записи с прежними идентификаторами и значениями

### Requirement: Сохранение при сбое процесса

Система MUST сохранять все записи, создание которых было подтверждено до аварийного завершения процесса, при исправном диске и без отключения питания. Для операции без полученного подтверждения допускается наличие или отсутствие целой записи, но не частичная запись.

#### Scenario: Аварийная остановка после подтверждения
- **WHEN** процесс принудительно завершён после подтверждения создания и затем запущен с тем же хранилищем
- **THEN** подтверждённая запись доступна с прежними значениями и идентификатором

#### Scenario: Сбой во время записи
- **WHEN** процесс аварийно завершён во время создания до получения подтверждения и затем перезапущен
- **THEN** новая запись либо присутствует целиком, либо отсутствует, а ранее подтверждённые записи доступны

### Requirement: Ошибка сохранения

Система MUST возвращать ошибку при неудаче записи в хранилище и MUST NOT подтверждать успешное создание. Ранее подтверждённые записи MUST оставаться доступными после устранения причины ошибки, если носитель исправен.

#### Scenario: Место закончилось
- **WHEN** сохранение новой записи завершается ошибкой из-за отсутствия свободного места
- **THEN** пользователь или программа получает ошибку вместо подтверждения успеха
- **THEN** после освобождения места ранее подтверждённые записи доступны
